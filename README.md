The project is a rendition of the word game Hangman where the user gets a set amount of times to guess a letter to inevitably guess a word. This project offers three modes, easy, regular, and hard. With unique challanges to each, the goal is to guess the word within the alotted attempts.
To start, type in your mode and word, once word is guessed you can re-enter another mode and word.
